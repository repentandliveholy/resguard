Three Ways to Run

Pick the lightweight daemon, the terminal dashboard, or the desktop app — all sharing the same core governor.

CLI & Daemon resguard

Runs with minimal overhead (<0.2% CPU). 3-zone CPU governor (Soft QoS, High Duty-Cycle, Hard Cap) plus RAM/Swap/Low-SSD emergency pause.

Terminal TUI rs-tui

Interactive htop/btop-style dashboard via resguard --tui with live sparklines, searchable process table, QoS/Pause/Protect keys, and threshold editor.

Desktop App RS Dash

Native Rust eframe/egui GUI with live time-series plots, hover crosshairs, daemon coexistence detection, log tailer, and config.toml editor.

Install as a Background Service launchd · systemd · schtasks

Run resguard automatically on login and restart on updates:

resguard --install-service
resguard --service-status
resguard --uninstall-service

Built-in Update & Auto-Update SHA256 verified

Check or install updates anytime, or let the background daemon keep itself current automatically:

resguard --check-update
resguard --update
# Enabled by default in daemon mode (toggle via --no-auto-update)
